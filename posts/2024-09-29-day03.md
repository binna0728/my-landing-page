## 03. 기초자료형01_실습과제_level1 (2)

## 실습 과제 — 환자 관리 통합 시나리오
### 요구사항
1) 환자 대기열 관리 (list 활용)
- 새로운 환자를 입력받아 대기열에 등록한다.
- 응급환자를 입력받아 대기열 맨 앞에 삽입한다.
- 특정 환자가 퇴원하면 대기열에서 삭제한다.
- 남아 있는 환자들을 알파벳 순으로 정렬한다.
- 최종 대기열을 출력한다.

2) 환자 건강 정보 기록 (dict 활용)
- 사용자에게 환자의 키(cm) 와 몸무게(kg) 를 입력받아 딕셔너리에 저장한다.
- 환자의 혈압을 입력받아 딕셔너리에 추가한다.
- 환자의 체중 정보를 꺼내면서 삭제한다.
- 최종 건강 기록과, 삭제된 체중 값을 출력한다.
아래 빈칸을 채워 **모든 assert** 를 통과시키세요.

먼저 필요한 라이브러리를 불러옵니다:
```python
# 🏥 환자 관리 통합 실습

# 1) 환자 대기열 관리 -----------------
queue = []

# 환자 등록
name = input("등록할 환자 이름: ")
queue.append(name)

# 응급환자 맨 앞 삽입
er = input("응급환자 이름: ")
queue.insert(0, er)

# 특정 환자 퇴원
leave = input("퇴원할 환자 이름: ")
queue.remove(leave)

# 알파벳 순 정렬
queue.sort()

print("최종 대기열:", queue)


# 2) 건강 정보 기록 -----------------
record = {}

# 키와 몸무게 입력 받아 저장
h = int(input("키(cm): "))
w = int(input("몸무게(kg): "))
record.update({"height": h, "weight": w})

# 혈압 입력 받아 저장
bp = input("혈압: ")
record.update({"blood_pressure": bp})

# 체중 데이터 꺼내기
removed = record.pop("weight")

print("최종 건강 기록:", record)
print("삭제된 체중 값:", removed)
```

**출력:**
```
최종 대기열: ['김코딩']
최종 건강 기록: {'height': 180, 'blood_pressure': '100'}
삭제된 체중 값: 80
```

# 🏥 환자 관리 통합 실습

## 문제 1) 리스트 기본 메서드
- `append, remove, sort, reverse, insert, pop, clear, extend` 를 사용해 요구사항을 만족하세요.

먼저 필요한 라이브러리를 불러옵니다:
```python
fruits = ["apple", "banana", "cherry"]
fruits.__class__  # 타입 힌트용 무해한 표현

# 1) 맨 뒤에 "orange" 추가
fruits.append("orange")
# 2) "banana" 삭제 (처음 하나)
fruits.remove("banana")
# 3) 인덱스 1 위치에 "grape" 삽입
fruits.insert(1, "grape")
# 4) 더 많은 과일(kiwi, mango) 이어 붙이기
more = ["kiwi", "mango"]
fruits.extend(more)
# 5) 알파벳 오름차순 정렬
fruits.sort()
# 6) 순서 뒤집기
fruits.reverse()
# 7) 인덱스 0 요소를 꺼내어 변수 first_out 에 저장
first_out = fruits.pop(0)

assert first_out is not None and isinstance(fruits, list)
assert set(fruits).issubset({"apple","cherry","grape","kiwi","mango","orange"})
print("✅ 문제 1 통과 | fruits:", fruits, "| first_out:", first_out)
```

**출력:**
```
✅ 문제 1 통과 | fruits: ['mango', 'kiwi', 'grape', 'cherry', 'apple'] | first_out: orange
```

## 문제 4) 집합(Set) 메서드/연산
- `add, remove, discard, clear, union, intersection, difference` 를 사용하세요.

실행 결과:
```python
a = {1,2,3}
b = {3,4,5}

a.add(10)       # add
u = a.union(b)    # union
i = a.intersection(b)    # intersection
d = a.difference(b)    # difference (a-b)

a.remove(2)        # remove 2
a.discard(99)       # discard 99 (에러 없어야 함)

assert u == {1,2,3,4,5,10}
assert i == {3}
assert d.issuperset({1,10}) and 3 not in d
print("✅ 문제 4-1 통과 | a:", a)

a.clear()         # clear
assert a == set()
print("✅ 문제 4-2 통과 | cleared a:", a)
```

**출력:**
```
✅ 문제 4-1 통과 | a: {10, 1, 3}
✅ 문제 4-2 통과 | cleared a: set()
```

## 문제 7) `in` / `not in`
