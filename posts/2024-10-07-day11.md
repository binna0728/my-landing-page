## 3. 간단한 결측치 채우기 (중앙값)

각 컬럼의 **중앙값**으로 NaN을 채웁니다.

실행 결과:
```python
for col in df.columns:
    if df[col].dtype == "object":
        df[col] = df[col].fillna(df[col].mode()[0])
    else:
        df[col] = df[col].fillna(df[col].median())
```

## 4. 각 컬럼 시각화

- **숫자형**: 값의 종류가 적으면(예: Outcome=0/1) → 막대 그래프  
               값이 많으면 → 히스토그램  
- **문자형/범주형**: 빈도 막대 그래프

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

sns.set(style="whitegrid")

# ID 컬럼 제외
cols_to_plot = [col for col in df.columns if col.lower() not in ["id", "patientid", "index"]]

for col in cols_to_plot:
    plt.figure(figsize=(6, 4))
    
    # 수치형 변수인 경우
    if pd.api.types.is_numeric_dtype(df[col]):
        unique_count = df[col].nunique()
        
        # 고유값이 적으면 (예: 0/1 등 이산형)
        if unique_count <= 10:
            sns.countplot(x=col, data=df, palette="pastel")
            plt.title(f"{col} - Countplot (numeric discrete)")
        
        # 값이 많으면 → 히스토그램
        else:
            sns.histplot(df[col], kde=True, bins=20, color="skyblue")
            plt.title(f"{col} - Histogram (numeric continuous)")
    
    # 문자형 / 범주형 변수인 경우
    else:
        sns.countplot(
            x=col,
            data=df,
            order=df[col].value_counts().index,
            palette="muted"
        )
        plt.title(f"{col} - Countplot (categorical)")
```

# 정렬된 순서로 히트맵

sns.heatmap(
    df[sorted_cols].corr().loc[['Outcome']],
    annot=True,
    fmt=".2f",
    cmap="coolwarm",
    cbar_kws={"shrink": 0.5},
